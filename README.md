# Cars Dealership - Full Stack Application

This application is a full-stack car dealership platform built as part of the IBM Full-Stack Software Developer Capstone Project. It provides customers with national branch information, dealer reviews, and sentiment analysis for customer feedback.

## Tech Stack
* **Frontend:** React, HTML5, CSS3, JavaScript, Bootstrap
* **Backend:** Python/Django, SQLite (Car Models & Authentication)
* **Microservices:** Node.js, Express, MongoDB (Dealerships & Reviews)
* **Sentiment Analyzer:** Python, Flask, NLTK
* **Deployment & CI/CD:** Docker, Kubernetes, IBM Cloud Code Engine, GitHub Actions
